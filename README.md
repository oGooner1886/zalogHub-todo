# ZalogHub ToDo App

Тестовое задание  в компанию **ZalogHub**.

Приложение представляет собой быстрый, удобный и адаптивный список задач с сохранением состояния в `localStorage`.

---

## Затраченное время
- **Примерное время выполнения:** ~45 минут

---

## Реализованный функционал

1. **Добавление задач:**
   - Поле ввода с кнопкой «Добавить» и поддержкой отправки по нажатию клавиши `Enter`.
   - **Валидация:** невозможно добавить пустую задачу или строку, состоящую исключительно из пробелов. В случае попытки выводится предупреждение.
2. **Переключение статуса (выполнено / не выполнено):**
   - Переключение по клику на кастомный чекбокс или на текст задачи.
   - **Визуальное отличие:** выполненные задачи зачёркиваются, приглушаются по цвету и получают зелёный индикатор выполнения.
3. **Удаление задач:**
   - Кнопка удаления для каждой задачи с плавной анимацией и подтверждающим состоянием наведения.
4. **Фильтрация:**
   - Три режима фильтрации: **«Все»**, **«Активные»**, **«Выполненные»**.
   - Отображение счётчиков количества задач прямо на вкладках фильтра.
5. **Сохранение в `localStorage`:**
   - Все задачи сохраняются локально в браузере.
   - Данные остаются на месте после перезагрузки страницы или повторного открытия браузера.
   - Предусмотрена обработка ошибок (`try / catch`) на случай работы в приватном режиме или при повреждении данных.
6. **Интерактивные возможности и дизайн:**
   - **Интерактивный стрип дат (Date Strip):** переключение между днями недели и режимом «Все дни», индикатор наличия задач на каждый день.
   - **Анимированный прогресс-бар:** динамический расчёт процента выполнения задач на выбранный день с поздравлением при 100%.
   - **Современный визуальный стиль:** фоновые градиенты свечения (Ambient Glow), мягкое стекло (Glassmorphism), плавные микро-анимации.
   - **Темы оформления (Стандартная ☀️ / Осенний вайб 🍂):** переключатель в шапке (Солнце / Осенний лист) с тёплой палитрой терракоты, тыквенного янтаря и сохранением выбора в `localStorage`.
   - **Счётчик оставшихся задач:** с корректным склонением слов в русском языке (*«1 задача»*, *«2 задачи»*, *«5 задач»*).
   - **Кнопка «Очистить выполненные»:** появляющаяся при наличии завершённых дел.
   - **Информативные Empty states:** состояния при отсутствии задач для каждого фильтра и дня.
   - **Доступность:** поддержка `aria-label`, фокусов и семантической разметки.

## 💻 Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-username>/zaloghub-todo.git
cd zaloghub-todo
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки (dev server)
```bash
npm run dev
```
После запуска проект будет доступен по адресу `http://localhost:5173` **или** `http://127.0.0.1:5173`.

### 4. Проверка типов и сборка для продакшена
```bash
npm run build
```
Готовая оптимизированная сборка сформируется в папке `dist/`.

### 5. Предпросмотр продакшен-сборки
```bash
npm run preview
```

### 6. Запуск линтера
```bash
npm run lint
```
